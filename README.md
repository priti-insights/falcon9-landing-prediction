## Project Overview

The goal of this project is to analyze SpaceX Falcon 9 launch data and explore the factors that influence the successful landing of the first stage. The project follows a data science workflow, including data collection, data wrangling, exploratory data analysis, data visualization, and machine learning.

Predicting first-stage landing success can help us understand launch outcomes and explore how data science techniques can support cost analysis in the commercial space industry.

## Objectives

- Collect and prepare SpaceX launch data.
- Perform data wrangling and exploratory data analysis.
- Analyze launch outcomes using SQL queries.
- Visualize launch sites and launch success patterns.
- Build and evaluate machine learning classification models.
- Identify factors associated with successful Falcon 9 first-stage landings.

## Technologies Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn, Plotly
- **Database:** SQL
- **Geospatial Visualization:** Folium
- **Machine Learning:** Scikit-learn
- **Development Environment:** Jupyter Notebook

## Project Workflow

### 1. Data Collection
Collect SpaceX launch information using available API data and web-scraping techniques.

### 2. Data Wrangling
Clean the data, handle missing values, transform variables, and prepare the dataset for analysis.

### 3. Exploratory Data Analysis
Explore launch outcomes, payload mass, launch sites, orbit types, and other relevant features.

### 4. SQL Analysis
Use SQL queries to investigate launch records and identify patterns in the data.

### 5. Data Visualization
Create visualizations to explore relationships between launch characteristics and landing outcomes. Use geospatial visualization to examine launch-site locations.

### 6. Machine Learning
Develop classification models to predict Falcon 9 first-stage landing outcomes and evaluate their performance.
